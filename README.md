# susf/.github

Org-wide defaults for SUSF. Changes here affect every repo, so they need a review from @susf/leads.

| Path | Effect |
| --- | --- |
| `profile/README.md` | Public org profile page |
| `.github/ISSUE_TEMPLATE/` | Default issue forms for repos without their own |
| `.github/pull_request_template.md` | Default PR description for repos without their own |
| `.github/workflows/python-ci.yml` | Reusable CI, called by every Python repo |
| `workflow-templates/` | "SUSF Python CI" option under Actions → New workflow |
